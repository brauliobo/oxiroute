What is in the runtime

Five layers. One status vocabulary.

Open a layer for the useful path, the concrete example, and the boundary that keeps the claim honest.

PARTIAL

Route HTTP and opaque TCP without hiding the policy.

01
H1

Reverse HTTP

Deterministic host/path/method routing, WebSocket upgrades, request limits, retries, and health-aware pools.

L4

TCP relay

Opaque bytes, half-close, backpressure, socket/DNS/Unix endpoints, and bounded connection lifetimes.

TLS

Explicit TLS

Exact, wildcard, and default SNI selection with verified upstream TLS, SNI, custom CA, and ALPN policy.

Not implied: HTTP/3 daemon listeners, UDP relay, weighted balancing, passive ejection, and cache request-path integration.
IMPLEMENTED

Inspect the generation before editing the source.

02
API

Loopback management

Typed JSON for status, monitoring, topology, configuration validation, revision-safe saves, and generation actions.

UI

Runtime observatory

Vue 3 and build-time Pug expose process, listener, pool, endpoint, topology, and RTMP state with stale/error labels.

REV

Prepare then activate

Complete candidates publish behind a readiness gate. A failed candidate leaves the active generation unchanged.

Security boundary: configuration writes need the bearer token and disk revision. The management schema remains loopback-only.
PARTIAL

Publish, fan out, and record the media you can explain.

03
RTMP

Live sessions

Simple/complex handshakes, publish/play roles, duplicate-publisher rejection, metadata, and keyframe gating.

REC

Bounded recorders

Continuous/manual policies, safe names, rotation, quotas, nonblocking queues, and atomic publication.

OBS

Exact snapshots

Stream, publisher, viewer, codec, relay, recorder phase, and redacted relative-file observability.

Current codec boundary: legacy AVC/AAC FLV recording is supported; enhanced AVC, HEVC, and AV1 remain observable but not recordable.
PARTIAL

Import the shape, retain the reason, block the gap.

04
NGX

nginx

Bounded include graphs, HTTP/RTMP subset lowering, provenance, and diagnostics for non-equivalent behavior.

HAP

HAProxy

Ordered roots, preprocessing fingerprints, HTTP/TCP subset lowering, stats-page boundaries, and source maps.

SQD

Squid

Direct-forward subset with ACL ordering, Basic auth, resolved destination policy, and explicit cache externalization.

Cutover rule: `report` is evidence, `preview` is a finalized candidate, and neither command rewrites the native source tree.
STAGED

Make replacement a protocol, not a best-effort restart.

05
FSM

Deterministic states

Platform-neutral lifecycle and replacement state machines carry bounded identities, revisions, and outcomes.

UNX

Unix transport

Descriptor validation, credential transport, and safe ownership boundaries support the Linux path.

M/W

Master and worker

Cross-process listener ownership and authenticated replacement are staged for a future production gate.

Default today: the public production entry point remains direct `oxiroute serve`; the supervised path is not silently selected.

See the control plane

A dashboard that keeps live state and source state apart.

The admin UI is for inspection and review, not magic. Every panel labels whether it is showing an active generation, a disk revision, or a candidate that is not active.

A
Stale is a state.

Transient refresh errors retain the last valid sample and say so. Zero is not a substitute for missing evidence.

B
Redaction is a feature.

Topology and recorder views omit private keys, roots, token paths, and stream query arguments.

C
Controls are capability-gated.

Manual recording controls only appear when a live publisher, manual recorder, and supported codec make the action valid.

The operating model

Source to generation, in four moves.

01

Resolve

Decode bounded KDL, Lua, HOCON, UCI, or explicitly named native references into one typed model.

source -> canonical
02

Prepare

Validate routes, pools, identities, credentials, stores, assets, and listener reservations before publication.

canonical -> candidate
03

Publish

Open the candidate behind an accept gate only after readiness; keep the previous generation for drain or rollback.

candidate -> active
04

Explain

Expose revisions, health, counters, topology, diagnostics, and stable outcomes through CLI, API, and UI.

active -> evidence
Why not edit listeners in place?

A complete generation gives routing, TLS, health, capacity, recording, and listener identity one consistent snapshot. Invalid changes can be rejected without leaving half of the old plan and half of the new one.

Why are counters sometimes strings?

Cumulative values can exceed JavaScript's safe integer range. The API returns exact decimal strings for those counters so the UI and automation do not silently round evidence.

Why does an import report block?

Native behavior that changes routing, security, TLS, listener, or upstream semantics must be represented or the affected service cannot be claimed equivalent. The importer keeps the reason rather than inventing a fallback.

Read this before deploying

The boundary is part of the product.

OxiRoute is intentionally smaller than the list of projects it can study. Current support is explicit so a migration does not confuse parsing with runtime parity.

Current capability status
SurfaceStatusMeaning now
HTTP reverse proxyPARTIALStrong HTTP/1 slice plus tested TLS/H2/WebSocket/gRPC paths; broader conformance remains.
TCP relayPARTIALOpaque socket/DNS/Unix relays with bounded lifecycle and health behavior; UDP is not included.
Management UI/APIPARTIALLoopback observability and revisioned config control; certificate/import/event views remain incomplete.
RTMP live/recordingPARTIALLive publish/play, fanout, catalog, and legacy AVC/AAC FLV recording are integrated.
Native importsPARTIALStrict subsets of nginx, HAProxy, and Squid can report and sometimes finalize; no full parity.
Cache / HTTP/3 / UDPPLANNEDFoundations or roadmap work exist, but these are not active daemon capabilities.
Not a firewall or NAT engine

Transparent interception, DNAT, SNAT, MASQUERADE, policy routing, conntrack, ICMP, and arbitrary IP protocols belong to kernel or separate privileged systems.

Not a drop-in Squid/nginx/HAProxy replacement

Import is conservative and product-specific. Unsupported ACL, cache, rewrite, process, or module behavior blocks rather than disappearing.

Not remote multi-user administration

Management is loopback-only in the current schema. Recorder controls have an even narrower pre-alpha boundary and must not be exposed remotely.
