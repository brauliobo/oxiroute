# Reference

Reference pages answer "what exact command, field, endpoint, or status does this system expose?"
They intentionally link to the longer normative specifications rather than replacing them.

- [CLI](CLI.md): command families, output modes, auth, and stable exit categories.
- [API](API.md): management/statistics routes and revision behavior.
- [Configuration](CONFIGURATION.md): source formats, examples, and save rules.
- [Management CLI](../MANAGEMENT_CLI.md): complete operation matrix and HAProxy mapping.
- [API/UI specification](../API_UI_SPEC.md): response fields, errors, and browser contract.
- [Configuration specification](../CONFIG_SPEC.md): complete typed schema and bounds.
- [Configuration formats](../CONFIG_FORMATS.md): exact source mappings and composition.
- [Compatibility matrix](../COMPATIBILITY.md): current feature status.
